# KakaoTalk Demo (Spec-Driven)

이 프로젝트는 PRD.md와 design_reference.md를 단일 소스 오브 트루스로 삼아 개발됩니다.

## 시작하기

1) 의존성 설치

```
npm run setup
```

2) 개발 서버

```
npm run dev
```

3) 환경변수

`.env` 에 다음을 설정하세요.

```
GEMINI_API_KEY=your_key
```

## 스크립트

- `npm run dev` – 로컬 실행
- `npm run build` – 프로덕션 빌드
- `npm run start` – 빌드된 앱 실행
- `npm run lint` – Next.js ESLint
